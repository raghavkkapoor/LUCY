# Play Hawken OST
## Goal
Open the exact HAWKEN original game soundtrack by Paper Sound in Spotify and start playback.
## Method
Uses the Spotify album URI `spotify:album:0UNTrituFTZdMBUppnrk8K`, then Windows Global System Media Transport Controls to issue Play.
## Stability / Risk
Low risk. This only changes Spotify playback state and opens an existing album.
## YouTube diagnostic
YouTube itself was verified reachable through DNS, HTTPS, and Lucy's CDP-controlled Chrome. The earlier inability to open it was not a global YouTube outage.
